Trumpet :3

January 17, 2025 — ~raidopaizer

I write here, the wonders of the soprano brass instrument

THE TRUMPET!!!

Obviously the best instrument there is to play,
it’s light, easy to learn, easy to march with, litterally anything.
it’s very well known for jazz, solos, screaming, and being the best instrument there is(alongside the altosax)

well you’re probably like: “waid!! is thewe any othew gweat instwuwment beside the gweat sopwano bwass twuwmpet?”
and im here to tell you yes!!

Ill go ahead and put them in a list below :3

These are mainly ones you’d find in a marching show , winds and non winds

Bb Trumpet ( the standard )
Flugelhorn ( like a softer tone trumpet, ask hayden )
Recorder ( im half serious about this one )
Flutes ( Silly professional whistle )
Baritone ( marching varient, I love the sound that comes out of these )
Tenor/Alto Sax ( THE Jazz Instrument, gotta love giant steps )
Contrbass Bugle ( Marching tuba, Really cool )
Oboe ( This one takes skill, I like the sound, squeeky )
French Horn ( That one instrument in every game that people think is a trumpet )
Pit ( I’m not listing all of these )

Here’s some I don’t like much ( either cause of preference, or the kids who play it )

Trombone ( Yeah whoo slidy slidy, but! so many areas to mess up, too far on slide, too close, drop the slide.. just no )
Clarinet ( weird kids, squeek a lot, don’t let the gremlin near water )
Concert Tuba ( first of all, ouch, second of all still ouch… )
Baritone Sax ( Weirdos. just choose an alto )
Battery ( too loud, scary, you can only listen if behind or near )
Mellophone ( stop. )

Anyways, This is my spiel about instruments, I know it’s called “Trumpet :3”
Ima quickly speedrun why trumpets are great

WOW! WOW! So Bright the pipirpirpiripi, easy fingerings, easy note reading, accidentals not so much….., The sound UWA~ UWA~~.
almost every part the trumpet gets is a lead part, after all we’re color group 4 the lead group!!!
